ADDITIONAL API ENDPOINTS:
================================================================================

Health Check:
GET https://starflix9.vercel.app/api/health

User Management:
POST https://starflix9.vercel.app/api/user

Favourites:
GET    https://starflix9.vercel.app/api/favourites/:userId
POST   https://starflix9.vercel.app/api/favourites/:userId
DELETE https://starflix9.vercel.app/api/favourites/:userId/:movieId

Watchlist:
GET    https://starflix9.vercel.app/api/watchlist/:userId
POST   https://starflix9.vercel.app/api/watchlist/:userId
DELETE https://starflix9.vercel.app/api/watchlist/:userId/:movieId

Reviews:
GET    https://starflix9.vercel.app/api/reviews/:userId
POST   https://starflix9.vercel.app/api/reviews/:userId
PUT    https://starflix9.vercel.app/api/reviews/:userId/:reviewId
DELETE https://starflix9.vercel.app/api/reviews/:userId/:reviewId

NOTES:
================================================================================

1. The API root endpoint (/api) returns a JSON response with API information and available endpoints.

2. All API endpoints require proper authentication (Firebase ID passed as userId parameter).

4. After deploying the changes, the /api endpoint should work correctly. If you still see 404, ensure:
   - Changes are committed and pushed to your repository
